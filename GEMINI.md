# GEMINI.md — SellerSalt Agent Guidelines

This file used to be a full duplicate of `AGENTS.md`, maintained
separately. As of 2026-08-19 that duplication was retired — two copies of
the same rules drift out of sync (this one still cited `shops_w`/`billing_r`
as required OAuth scopes months after both were removed for Etsy
compliance reasons, and pointed at a stale doc reference).

**Read `AGENTS.md` — it is the single, canonical instruction set for every
agent working in this repository (Claude, Gemini, Antigravity, or
otherwise).** Start there, then `docs/SELLERSALT-HANDOFF.md` for the fast
practical orientation.

Nothing Gemini-specific is required beyond that: this repository doesn't
currently have any Gemini-only tooling, prompts, or workflow that differs
from the general agent rules.
