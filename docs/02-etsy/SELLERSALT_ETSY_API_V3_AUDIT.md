## 2. Rate Limits, Quota & Commercial Access

1. **Shared Key Limitations**:
   - Limit: 5 requests/sec, 5,000 requests/day per application keystring.
   - PQueue enforcement: `intervalCap: 8`, `interval: 1000ms`.
2. **Token Lifecycle**:
   - Access tokens expire in ~3600 seconds (1 hour).
   - Refresh tokens must be exchanged before expiration using `https://api.etsy.com/v3/public/oauth/token`.
3. **Data Retention & Caching**:
   - No mass downloading or indefinite caching of marketplace PII.
   - Cached responses must respect defined TTLs (Search: 6h, Shop: 24h, Taxonomy: 7d).

## 3. Data Honesty & Labeling Standards

- If data comes directly from Etsy: Label **`[ACTUAL ETSY DATA]`**.
- If calculated from Etsy data: Label **`[ESTIMATED]`** with transparent formula.
- If generated by SellerSalt heuristics: Label **`[SELLERSALT SCORE]`**.
- If from non-Etsy sources: Label **`[EXTERNAL DATA]`**.
