## 3. Epistemological Signal Classification Contract

Every metric presented across marketing and product surfaces adheres to strict provenance:

| Signal Class | Definition | Example in UI |
|---|---|---|
| **`OBSERVED`** | Directly captured from public catalog or official API. | Median Listing Price: `$34.99`, Review Count: `142` |
| **`DERIVED`** | Calculated deterministically from observable data. | Price Positioning: `Upper-Mid Market`, Saturation % |
| **`ESTIMATED`** | Multi-factor statistical models with explicit confidence. | Opportunity Score 3.0: `84 / 100` (High Confidence) |
| **`USER_DERIVED`** | Computed strictly from merchant-entered costs. | Landed Contribution Margin: `62%` |
| **`UNAVAILABLE`** | Private/inaccessible data is strictly `null` (never 0). | Competitor Monthly Revenue: `Unavailable` |
